# coba-react
This project builded by react and vite.

## create project

```bash
npm create vite@latest
```
## install package (from file package.json)

```bash
npm install
```
## run project (on dev)

```bash
npm run dev
```
## install bootstrap

```bash
npm i bootstrap
```
## import compiled css 

```bash
import 'bootstrap/dist/css/bootstrap.min.css';
```
